# Spec Delta

## Purpose

起動ヘッダの最上部に Spirits の ASCII アートをカラー表示で追加し、ツールの視覚的アイデンティティを明確にする。ヘッダ全体の構成、`quietStartup`、起動ヘルプの展開追従は `product-identity` が規定し、この capability はアート本体と行ごとの色に絞る。

## ADDED Requirements

### Requirement: 起動ヘッダに ASCII アートを表示する
システムは対話モードの起動ヘッダに、次の Spirits ASCII アートを 4 行として表示しなければならない。(SHALL)

```
.--------.
| Spirits \__
| __| --------
| : ~~~~~
```

#### Scenario: 折りたみ状態でアートを表示
- **WHEN** コンパイル済み `spirits` を対話モードで起動し、起動ヘルプが折りたまれている
- **THEN** 起動ヘッダに ASCII アートの 4 行が表示される

### Requirement: ASCII アートの各行に異なるカラーを使う
システムは ASCII アートの各行をテーマカラーで描画し、4 つの行すべてに互いに異なるテーマカラートークンを割り当てなければならない。(SHALL)
ビルトインテーマ(dark / light)では、truecolor と 256 色のどちらのカラーモードでも、4 行の解決後の色が互いに異なっていなければならない。(SHALL)
端末の色に依存するテーマ(system テーマで端末の色が未報告、または背景色を報告しない端末)で解決後の色が重なることは許容する。

#### Scenario: 各行に異なるトークンを割り当てる
- **WHEN** 起動ヘッダを描画する
- **THEN** 4 つの行すべてが互いに異なるテーマカラートークンで描画される

#### Scenario: ビルトインテーマで解決後の色が異なる
- **WHEN** ビルトインテーマ dark または light を truecolor または 256 色で使い、起動ヘッダを描画する
- **THEN** 4 つの行の解決後の色が互いに異なる

#### Scenario: テーマカラーに従う
- **WHEN** 別のテーマを設定した対話モードで起動ヘッダを描画する
- **THEN** ASCII アートの各行はそのテーマのカラー解決で表示され、アート本文の文字列はテーマによらない
