# Tasks

テストのケース名は、既存のものは実在する名前、新規のものは「新規」と書いたとおりの接頭辞で付ける。`-t` はその接頭辞に一致させる。パッケージの型検査は `cd packages/spirits && bun run check`。

`- [ ]` に戻した項目は、検証(verify2)の指摘への対応を「差し戻し」として追記したものである。指摘 ID の C は重大、W は警告、S は成果物の食い違い、G は提案を表す。S は成果物(spec / design / tasks)の側で解決済みで、実装側の作業は該当項目に書いた。差し戻しの内容は、元の項目の内容に追加する(元の検証も引き続き通す)。
